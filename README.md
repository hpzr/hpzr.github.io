# Minimal academic homepage

This is a one-page, responsive website for Peter Herbszt-Romanek. It is a single `index.html` file with no framework, build step, tracking, or external assets.

## Review before publishing

1. Open `index.html` in a browser and check the name, wording, and current project descriptions.
2. The Contact section links to your GitHub profile. If you prefer direct contact, add your public email or institutional profile link. For an email link, use `<a href="mailto:name@example.org">name@example.org</a>`.
3. Add publications or a CV only when you have the exact entries and files. The page currently makes no publication claims.

## Publish at your GitHub username URL

1. On GitHub, create a repository named **hpzr.github.io** under your `hpzr` account. If it already exists, review its files before replacing anything.
2. Upload `index.html` and `.nojekyll` to the **root** of the repository. You may also upload this README.
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Visit `https://hpzr.github.io/`. GitHub says publishing may take up to ten minutes.

To change the site later, edit `index.html` in GitHub and commit.

GitHub's instructions: [Quickstart](https://docs.github.com/en/pages/quickstart) · [Publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
